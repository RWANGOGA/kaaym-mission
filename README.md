# KAAYM Mission - Makerere Chapter

A Next.js website for KAAYM (Kampala Association of Anglican Youth Missioners) Makerere Chapter featuring a vertical media gallery and events display.

## Features
- Vertical media gallery with automatic rotation
- Full-screen images and videos
- Responsive design
- YouTube integration
- Multiple pages (About, Contact, Support, Media, Events)

## Technologies
- Next.js 15
- TypeScript
- Tailwind CSS
- React

## Getting Started

1. Clone the repository:
\`\`\`bash
git clone https://github.com/RWANGOGA/kaaym-mission.git
\`\`\`

2. Install dependencies:
\`\`\`bash
npm install
\`\`\`

3. Run development server:
\`\`\`bash
npm run dev
\`\`\`

4. Open http://localhost:3000

## Pages
- `/` - Home page
- `/events` - Vertical media gallery
- `/media` - Media gallery
- `/about` - About KAAYM
- `/contact` - Contact page
- `/support` - Support page
